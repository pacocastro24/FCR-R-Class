Q4. Use the Shapiro–Wilk test to assess whether Volume is normally distributed. Report the p-value and state whether the data are normally distributed.

library(ggplot2)
data("trees")

shapiro.test(trees$Volume)
## 
##  Shapiro-Wilk normality test
## 
## data:  trees$Volume
## W = 0.88757, p-value = 0.003579
#The Shapiro-Wilk test shows a p value of 0.003579 for tree volume. Based on this we can say that the data is not normally distributed. p value > 0.05.
